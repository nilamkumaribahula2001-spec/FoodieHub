# 🍔 FoodieHub – Online Food Ordering System

FoodieHub is a web-based food ordering application where users can explore food items, add products to their cart, place orders and manage their profiles.

## ✨ Features

- Attractive and responsive food ordering interface
- Food menu and search functionality
- Shopping cart with quantity controls
- Checkout with Cash on Delivery
- Order confirmation and order history
- User signup and login
- User profile management
- Food reviews
- Admin dashboard
- Order status management
- Sales report export

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MySQL
- bcryptjs

## 📂 Project Structure

- `index.html` – Home page
- `cart.html` – Shopping cart
- `checkout.html` – Checkout page
- `login.html` – Login page
- `signup.html` – Registration page
- `admin.html` – Admin dashboard
- `server.js` – Backend server
- `style.css` – Website styling

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Install the dependencies:

   `npm install`

4. Configure your MySQL database and `.env` file.
5. Start the backend:

   `node server.js`

6. Open `index.html` using Live Server.

## 🔐 Environment Variables

Create a `.env` file locally and add your own database credentials:

```env
DB_HOST=localhost
DB_USER=your_username
DB_PASSWORD=your_password
DB_NAME=foodiehub
DB_PORT=3306
```

**Never upload your `.env` file or database passwords to GitHub.**
